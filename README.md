# 🎙️ Balabol (Аналог Discord)

Современный легковесный веб-мессенджер с текстовыми каналами, голосовой связью WebRTC с минимальной задержкой, нейросетевым/браузерным шумоподавлением и **индивидуальной регулировкой громкости каждого собеседника**.

---

## ⚡ Быстрый старт на текущем компьютере

### Вариант 1: Запуск в 1 клик (Windows)
* **Для разработки с живой перезагрузкой**: запустите файл [`start-dev.bat`](file:///c:/Users/ryabs/Desktop/Balabol/start-dev.bat)
* **Для рабочего запуска (Production)**: запустите файл [`start-prod.bat`](file:///c:/Users/ryabs/Desktop/Balabol/start-prod.bat)

После этого откройте в браузере: **`http://localhost:3001`** (или `http://localhost:5173` в режиме dev).

## 🧪 Как протестировать связь и громкость в одиночку

1. Откройте **обычную вкладку браузера** по адресу `http://localhost:3001` и нажмите кнопку быстрого входа **«Alex_Gamer»**.
2. Откройте **вкладку в режиме «Инкогнито»** (Ctrl+Shift+N) по адресу `http://localhost:3001` и войдите как **«Dmitry_PRO»**.
3. **Проверка чата**: напишите сообщение в `# общий-чат` — оно появится у обоих пользователей мгновенно без перезагрузки страницы.
4. **Проверка голоса**:
   * Нажмите на голосовой канал `🔊 Гостиная` в обеих вкладках.
   * Разрешите доступ к микрофону.
   * Произнесите что-нибудь: вокруг аватарки говорящего загорится **зеленая светящаяся пульсация**.
5. **Проверка раздельного звука**:
   * В карточке второго участника подвигайте ползунок **«Громкость»** (от 0% до 200%). Звук именно этого собеседника регулируется независимо от всей системы.
6. **Проверка шумодава**:
   * В правом верхнем углу голосового канала или в настройках (шестеренка внизу) включите переключатель **«Шумодав»**.

## 🖥️ Развертывание на старом игровом ПК со статическим IP

Ваш старый игровой ПК со статическим IP — отличная серверная площадка. Для запуска на нем есть два простых способа:

### Способ А: Через Docker Compose (Рекомендуется)
1. Установите Docker Desktop на ваш игровой ПК.
2. Скопируйте папку проекта на сервер (через Git или флешку).
3. В терминале выполните:
   ```bash
   docker compose up -d --build
   ```
   Приложение будет запущено и готово принимать входящие подключения на порту `3001`.

### Способ Б: Прямой запуск через Node.js
1. Установите Node.js на сервер.
2. В папке проекта запустите:
   ```powershell
   .\start-prod.bat
   ```

## 🌐 Настройка сети и роутера для доступа из интернета

Чтобы ваши друзья могли подключаться к вашему серверу из любой точки:

### 1. Проброс портов (Port Forwarding) в роутере
В веб-интерфейсе вашего домашнего роутера найдите раздел **Port Forwarding / Виртуальные серверы** и добавьте правила проброса на локальный IP-адрес вашего игрового ПК (например, `192.168.1.100`):

| Внешний порт | Внутренний порт | Протокол | Назначение |
| :--- | :--- | :--- | :--- |
| **80** | 80 | TCP | Веб-трафик / Сертификаты Let's Encrypt |
| **443** | 443 | TCP | Защищенный HTTPS (критично для микрофона!) |
| **3001** | 3001 | TCP | Сервер Balabol (если подключаться без обратного прокси) |
| **10000–20000** | 10000–20000 | UDP | Прямой голосовой трафик WebRTC |

### 2. Привязка домена и бесплатного SSL-сертификата (HTTPS)
> [!IMPORTANT]
> **Почему нужен HTTPS?**  
> Браузеры (Chrome, Firefox, Edge, Safari) из соображений безопасности **блокируют доступ к микрофону по обычному `http://`**, если это не `localhost`. Чтобы у друзей работал микрофон, подключение обязательно должно быть защищено сертификатом SSL (`https://`).

1. Привяжите бесплатный домен (например, на [DuckDNS.org](https://www.duckdns.org/) или свой купленный домен) типа `A-записи` к вашему статическому белому IP-адресу.
2. В файле [`Caddyfile`](file:///c:/Users/ryabs/Desktop/Balabol/Caddyfile) укажите ваш домен:
   ```caddy
   balabol.your-domain.duckdns.org {
       reverse_proxy localhost:3001
   }
   ```
3. Caddy **автоматически и бесплатно** получит доверенный SSL-сертификат Let's Encrypt и настроит безопасное HTTPS-соединение.

## 📁 Структура проекта

```
Balabol/
├── client/                     # Фронтенд (React 19 + Tailwind CSS + Lucide Icons)
│   ├── src/
│   │   ├── components/
│   │   │   ├── Chat/           # Окно сообщений, инпут, аватарки, автоскролл
│   │   │   ├── Voice/          # Сетка голосового канала, VAD, ползунки громкости
│   │   │   ├── Sidebar/        # Серверы, каналы, профиль, Mute/Deafen
│   │   │   ├── DM/             # Личные сообщения и звонки 1-на-1
│   │   │   ├── Modals/         # Настройки звука, тест микрофона, создание каналов
│   │   │   └── Auth/           # Экран входа и 1-клик тестовый вход
│   │   ├── context/            # AuthContext, SocketContext
│   │   ├── services/           # VoiceEngine (WebRTC + Web Audio GainNode & VAD)
│   │   └── utils/              # Звуковые эффекты (Web Audio API), конфиги
├── server/                     # Бэкенд (Node.js + Express + Socket.io)
│   ├── src/
│   │   ├── db/                 # База данных SQLite/JSON
│   │   ├── routes/             # REST API (auth, channels, messages, dms)
│   │   ├── socket/             # Обработчики чата, присутствия и WebRTC сигналинга
│   │   └── index.ts            # Сервер Express со статической раздачей клиента
├── Dockerfile                  # Production сборка контейнера
├── docker-compose.yml          # Запуск на сервере в 1 команду
├── start-dev.bat               # Быстрый запуск для разработки
└── start-prod.bat              # Запуск собранного приложения
```
