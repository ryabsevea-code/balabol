# 🎙️ Balabol 2.0 (Нативный децентрализованный P2P аналог Discord)

Высокопроизводительный децентрализованный мессенджер с нативным медиа-движком на **Rust**, сквозным шифрованием (E2EE), криптографической идентификацией **Ed25519**, синхронизацией данных **Loro CRDT**, системным захватом звука через **cpal**, нейросетевым шумоподавлением **DeepFilterNet**, **глобальным STUN/UPnP выходом в интернет**, **динамическими хостами (SFU Суперузлами)** и ультралегким десктопным интерфейсом на **Tauri v2 + Svelte 5**.

## 🌐 Ключевые возможности децентрализованной сети 2.0

1. **Глобальный интернет-выход без своих серверов (STUN + UPnP)**:
   * **STUN RFC 5389**: клиент при старте опрашивает публичные открытые узлы (`stun.l.google.com:19302`, `stun.cloudflare.com:3478`) и мгновенно узнаёт свой реальный внешний глобальный IP и рефлексивный порт.
   * **UPnP IGD авто-проброс**: приложение автоматически просит домашний роутер открыть UDP-порт `42420`, делая ваш компьютер полноценным хостом, доступным из глобального интернета.
   * В шапке приложения отображается глобальный статус: `🌐 <public_ip>:42420` с бейджем `UPnP`.

2. **Динамический выбор Хоста (SFU Суперузла) и мульти-хостинг**:
   * В групповом звонке любой клиент может стать хостом.
   * Алгоритм скоринга автоматически выбирает участника с наилучшим соединением (минимальный пинг, джиттер, открытый UPnP) в роли **SFU Хоста** (бейдж `👑 Хост`).
   * **Кластеризация нескольких хостов**: для больших групп выбираются Primary и Secondary хосты с транковым каналом между ними, распределяя нагрузку на домашние каналы.
   * **Бесшовный Failover (<1 сек)**: если текущий хост отключается, резервный узел подхватывает маршрутизацию без обрыва звонка.

3. **Peer Relay для участников с симметричным мобильным NAT (CGNAT)**:
   * Пользователи с мобильным 4G/5G интернетом направляют трафик через хост-релей. Благодаря **XChaCha20-Poly1305 E2EE**, хост не может расшифровать чужой разговор.

4. **Локальный поиск (Serverless LAN Auto-Discovery)**:
   * UDP-маяки на порту `42424` находят все компьютеры в домашней Wi-Fi сети за доли секунды без интернета.

5. **Глобальные инвайт-ссылки в 1 клик**:
   * Кнопка «Код инвайта» генерирует ссылку `bala://<pubkey>@<public_ip>:<port>`. Отправьте ее другу через Telegram или почту для прямого соединения через интернет.

6. **Управление комнатами (CRUD)**:
   * Создание текстовых (CRDT) и голосовых (Rust Audio) каналов по кнопке `+`.
   * Удаление комнат по иконке корзины 🗑️ с очисткой SQLite.

7. **Живой аудио-пайплайн и Эхо-тест**:
   * Захват микрофона через **CPAL (WASAPI, 48 kHz)**.
   * Кнопка **«Эхо-тест микрофона»** возвращает звук в наушники в реальном времени, а анимированный **VU-метр** визуализирует уровень речи.

## 🏛️ Архитектура и технологии

| Слой | Технологический стек | Преимущества |
| :--- | :--- | :--- |
| **Клиентское ядро** | **Rust + Tokio** (`core/`) | Работает в фоне, потребляя ~20 МБ ОЗУ (вместо 500+ МБ у Electron). |
| **Идентификация** | **Ed25519** (`balabol-crypto`) | Полная анонимность: публичный ключ = User ID (`bala:<hex>`), подпись всех пакетов. |
| **Шифрование** | **XChaCha20-Poly1305** | Сквозное шифрование (E2EE) сообщений и медиа-потоков. |
| **Local-First & CRDT**| **SQLite (WAL) + Loro CRDT** (`balabol-storage`) | Автономная работа при падении серверов, бесконфликтная дельта-синхронизация. |
| **Аудио-движок** | **cpal + DeepFilterNet** (`balabol-audio`) | Захват/вывод WASAPI на уровне ОС, программный микшер с индивидуальной громкостью (0–200%) и эхо-тестом. |
| **Сетевой транспорт**| **STUN + UPnP + UDP + Gossip** (`balabol-net`) | Авто-обнаружение по LAN, проброс портов на роутере, определение внешнего IP без своих серверов. |
| **Маршрутизация (SFU)**| **Raft выборы + Multi-Host SFU** (`balabol-sfu`) | Динамический выбор лучшего хоста, кластеризация для больших групп, failover за 1 секунду. |
| **Захват экрана** | **xcap (DXGI / DirectX)** (`balabol-capture`) | Нативный захват экранов и окон приложений с минимальной нагрузкой на GPU. |
| **Инфраструктура** | **Axum + DashMap** (`rendezvous/`) | Опциональный stateless трекер без БД, хранящий сопоставления в памяти с TTL 120 сек. |
| **Интерфейс** | **Tauri v2 + Svelte 5 + Tailwind** (`desktop/`) | Мгновенный отклик, вес установщика 4.0 МБ, системный WebView. |
