# 🎙️ Balabol (Децентрализованный P2P голосовой чат для геймеров)

**Balabol** — высокопроизводительное, сверхлегкое десктопное приложение для голосовой, видео и текстовой связи во время совместных игр и конференций. Приложение работает по полностью децентрализованной топологии **Full Mesh P2P**: без аренды серверов, без создания учетных записей и без передачи персональных данных третьим лицам.

В основе проекта — нативное ядро на **Rust**, сетевой транспорт **UDP + STUN + Port Spraying**, отказоустойчивый децентрализованный сигналинг **Nostr (NIP-01 over WSS)**, криптография **Secp256k1 + SHA-256**, аудио-пайплайн **cpal (WASAPI)** со сверхнизкой задержкой и современный интерфейс на **Tauri v2 + Svelte 5**.

---

## 🚀 Преимущества перед Discord и аналогами

* 🟢 **Полная децентрализация**: не требуется центральный сервер или регистрация. Комната создается за секунду, вход осуществляется по простому 6-значному коду.
* ⚡ **Минимальные задержки (Low-Latency)**: прямой обмен аудио- и видео-пакетами по протоколу UDP между участниками в обход промежуточных серверов.
* 🛡️ **Работа в любых сетях (NAT Traversal + WSS Fallback)**: автоматическое определение внешнего IP/порта через STUN, пробитие NAT через Port Spraying и незаметный автоматический переход на защищенный WSS-релей при строгом CGNAT.
* 🪶 **Ультралегкий вес и низкое потребление ресурсов**: потребление памяти составляет ~25–40 МБ ОЗУ (вместо 500+ МБ у Discord/Electron), минимальная нагрузка на CPU/GPU, что критически важно в тяжелых играх.
* 🎧 **Студийное звучание без искажений**: супер-широкополосный звук (24 kHz Super-Wideband HD), алгоритм Packet Loss Concealment (PLC), защита от хрипов и перегрузок (Soft-Knee Limiter) и интеллектуальный VAD (Voice Activity Detection).

## 🌐 Сетевая архитектура и технологии связи

```
                     +---------------------------------------+
                     |    Публичный пул Nostr WSS-релеев     |
                     |  (wss://nos.lol, relay.damus.io и др)  |
                     +-------------------+-------------------+
                                         ^
                 Сигналинг NIP-01 (WSS TLS) | Защищенный фолбэк при строгом NAT
                                         v
 +---------------------------+                      +---------------------------+
 |         Пир A             |<====================>|         Пир B             |
 |  (192.168.1.10 / Public)  |  Прямой UDP P2P      |  (192.168.0.21 / Public)  |
 +---------------------------+  (Super-Wideband HD) +---------------------------+
               ^                                                  ^
               |           Прямой UDP P2P (Full Mesh)             |
               +==================================================+
                                         |
                                         v
                            +---------------------------+
                            |         Пир C             |
                            |       (Участник 3)        |
                            +---------------------------+
```

### 1. Топология Full Mesh P2P
В активной ветке звонки происходят по симметричной схеме **Full Mesh**: каждый участник устанавливает прямое peer-to-peer соединение с каждым собеседником. Отсутствует единая точка отказа (нет выделенного хоста-сервера, падение которого прервало бы звонок).

### 2. Децентрализованный сигналинг через Nostr (NIP-01 over WSS)
* Для начального обмена сетевыми кандидатами (Signaling) не нужны собственные серверы.
* Приложение параллельно подключается к пулу независимых глобальных Nostr-релеев (`relay.damus.io`, `nos.lol`, `nostr.mom`, `relay.snort.social`, `relay.primal.net`, `nostr.oxtr.dev`, `eden.nostr.land`, `relay.nostr.bg`) по защищенному протоколу **WSS (Port 443, TLS)**.
* Сигнальный трафик неотличим от стандартного зашифрованного веб-трафика (HTTPS) и свободно проходит через любые корпоративные и провайдерские фильтры.
* Все анонсы и сообщения криптографически подписываются с использованием алгоритма **Secp256k1 Schnorr + SHA-256**.

### 3. Комплексный NAT Traversal
* **STUN RFC 5389/3489**: на старте сессии узел опрашивает географически распределенные STUN-серверы (Cloudflare, Google, Syncthing, SIPnet и др.) и получает свой внешний публичный IP и рефлексивный порт.
* **Физические LAN-адаптеры**: через Windows IP Helper API (`windows-sys` / `GetAdaptersAddresses`) движок считывает реальные адреса сетевых карт, отсекая виртуальные и loopback интерфейсы.
* **Port Spraying**: для пробития Restricted Cone NAT узел посылает пакеты не только на целевой порт, но и распыляет их по соседним портам (дельта ±10).
* **Punch / PunchAck**: быстрое двухстороннее рукопожатие фиксирует открытие прямого канала.

### 4. Бесшовный WSS Relay Fallback (для симметричных NAT и мобильного интернета)
Если между двумя участниками прямой UDP-канал заблокирован (например, мобильный интернет 4G/5G за строгим симметричным CGNAT), пакеты аудио и видео автоматически маршрутизируются через WSS-релеи. Разговор продолжается без обрывов.

## 🔊 Нативный аудио-движок на Rust

Разработан специально для гейминга с учетом высоких требований к качеству голоса и минимальной задержке:

1. **Super-Wideband HD Voice (24 kHz, 0–12 kHz)**:
   * Частота дискретизации 24 000 Гц обеспечивает чистый, естественный тембр голоса, в отличие от телефонного стандарта 8 кГц.
   * Размер кадра — 20 мс (480 сэмплов).

2. **Защита от клиппинга и хрипов (Soft-Knee Saturation Limiter)**:
   * Математический лимитер плавно компрессирует пики громкости выше 75%. Крик в микрофон или фоновый игровой взрыв не вызовут цифрового треска или дребезжания в наушниках тиммейтов.

3. **Антиалиасинговый ресэмплинг (FIR Filter)**:
   * Преобразование стандартного системного потока микрофона 48 kHz в 24 kHz выполняется через оптимизированный FIR-фильтр усреднения 2:1 без появления высокочастотных артефактов (алиасинга).

4. **Мульти-пиринговый адаптивный Jitter Buffer + PLC**:
   * Для каждого собеседника поддерживается независимый буфер.
   * В случае кратковременных сетевых потерь алгоритм **Packet Loss Concealment (PLC)** плавно затухает сигнал, исключая щелчки, и мгновенно возобновляет воспроизведение без накопления задержки.

5. **Голосовая активация (VAD с Hangover 300 мс)**:
   * Автоматическая активация по голосу с настраиваемым порогом чувствительности.
   * Функция «зависания» (hangover) удерживает передачу еще 300 мс после окончания фразы, предотвращая «съедание» окончаний слов.

6. **Watchdog авто-восстановления аудиоустройств**:
   * Фоновый наблюдатель отслеживает состояние микрофона и наушников. При случайном отключении или смене разъема гарнитуры аудио-тракт автоматически перезапускается без перезагрузки программы.

7. **Гибкое управление звуком в UI**:
   * Индивидуальная регулировка громкости каждого участника (0–200%).
   * Мастер-громкость, усиление микрофона (gain до 300%), визуальный индикатор уровня голоса (RMS VU-Meter), режим локального эхо-теста (loopback) и звуковые сигналы событий.

## 📹 Видео и трансляция экрана

* **Нативный захват экрана в Rust (Win32 GDI)**: сверхлегкий прямой захват экрана на уровне ОС (Win32 GDI Desktop Duplication) без браузерных диалогов и ограничений WebView2.
* **Smart Delta Detection**: алгоритм быстрого хэширования пропускает неизменившиеся кадры, снижая сетевой трафик практически до 0 КБ/с во время пауз и чтения текста.
* **Per-Peer Reassembly (Full Mesh)**: независимые сборщики чанков для каждого пира исключают коллизии при одновременной трансляции несколькими участниками.
* **Event-driven Push Architecture**: готовые кадры мгновенно эмитятся в UI через события Tauri (`p2p://video_frame`) с нулевой задержкой вместо устаревшего интервального опроса (polling).
* **Веб-камера**: плавный видеопоток через прямой `getUserMedia`.
* **Режимы отображения (UI Layouts)**:
  * **Split**: классический сплит — сетка участников/видео слева и чат справа.
  * **Stage (Fullscreen)**: разворачивание стрима экрана или видео во весь экран для комфортного просмотра игрового процесса.
  * **Chat**: полноэкранный текстовый чат с системными логами и статусом подключения.

| **Интерфейс (Frontend)** | **Svelte 5 (Runes) + Vite 6** | Быстрый, реактивный интерфейс без оверхэда виртуального DOM |
| **Стили и иконки** | **Tailwind CSS 3.4 + Lucide Svelte** | Современный темный геймерский дизайн |

## 🛠️ Разработка и сборка

### Предварительные требования
* **Rust** (stable toolchain) и Visual Studio C++ Build Tools.
* **Node.js** (v18+) и менеджер пакетов `npm`.

### Установка зависимостей
```powershell
cd desktop
npm install
```

### Запуск в режиме разработки (Dev Mode)
Запуск интерфейса с горячей перезагрузкой и одновременным запуском ядра Tauri:
```powershell
cd desktop
npm run tauri dev
```

### Запуск тестов
Для запуска тестов ядра (аудио-движок, лимитер, ресэмплинг, bincode-пакеты, сигналинг):
```powershell
cd desktop/src-tauri
cargo test --lib
```

### Сборка релизного файла
Сборка оптимизированного `.exe` файла и автоматическое копирование в папку `dist-release/`:
```powershell
cd desktop
npm run build:dist
```
Готовый исполняемый файл будет доступен по пути: [`dist-release/balabol.exe`](file:///c:/Users/ryabs/Desktop/Balabol/dist-release/balabol.exe).
